# EICP-FLAC-MODEL

This repository contains the numerical model and simulation scripts developed for my MSc Dissertation. 

## How to Run the Project

To verify the model and reproduce the results, you do not need to execute the individual scripts manually. All core functions and workflows are fully automated through the test suite.

### Quick Start
1. Ensure you have the required environment and dependencies installed.
2. Navigate to the root directory of the project.
3. **Just run the tests.** 

Executing the test suite will automatically trigger all the necessary underlying functions, run the simulations, and validate the model outputs.
